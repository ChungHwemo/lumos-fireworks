## 목표

일본어를 고르면 한글이 한 글자도 없다. 한국어·영어도 같은 규칙이다. 언어 전환 버튼도 예외가 아니다.

목록 배경은 예전 오로라(주황·남색·금)를 유지하고, 그 위에 색이 천천히 움직이게 한다. 밝음/어둠은 사용자가 고를 수 있다. 납작한 검정 한 장만 깔지 않는다.

## 안에 넣는 것

1. 기본 언어는 日本語. 저장값이 있으면 그것이 이긴다. 브라우저 언어는 보지 않는다.
2. 화면 문자열·지명·역·우천·좌석·통제·출처·언어 버튼은 고른 언어 하나만. 빠진 번역은 한글 시드로 채우지 않는다. 일본어는 일본어, 영어는 영어 또는 일본어 원어.
3. 언어 버튼 이름도 화면 언어로 쓴다. 일본어 화면의 한국어 버튼은 `韓国語`/`韓`이지 `한국어`/`한`이 아니다.
4. 목록·404·에러 뒤에 오로라 세 덩이가 있다. 위치와 색이 천천히 바뀐다. `prefers-reduced-motion: reduce` 이면 멈춘다.
5. 설정에 화면 색(기기/밝게/어둡게)이 있다. 목록 상단에 한 알 토글이 있다. 밝음은 실제 밝은 토큰을 쓴다. `data-theme` 만 있고 색이 그대로인 상태는 실패다.

## 밖에 두는 것

- 지리원 타일 위 일본어 지명(지도 데이터).
- 시드 JSON 스키마를 세 언어로 다시 짜는 일.
- 시간대·날씨에 맞춘 JS 테마.
- 새 언어.

## 성공

- `ja` 화면의 보이는 글자에 한글이 없다. 언어 전환 포함.
- `ko` 화면의 언어 버튼에 가나·한자가 없다.
- 일본어 사본이 비어 있으면 빈 문자열이지 한글 시드가 아니다.
- 목록 DOM에 `.aurora` 가 있고, 설정에 화면 색 전환이 있다.
- `npm test`, `tsc`, 브라우저에서 일본어 목록에 `한`/`한국어`가 없고 오로라가 움직인다.
